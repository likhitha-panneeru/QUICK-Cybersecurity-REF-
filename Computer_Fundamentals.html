Computer Fundamentals

The foundation for understanding how computers represent data, execute instructions, manage memory and storage, communicate with hardware, boot operating systems, run virtual machines, and support cybersecurity investigations.

1.1 Computer Basics

Definition — ComputerA computer is an electronic system that accepts input, processes data according to instructions, produces output, and stores data for later use. Modern computers combine hardware, firmware and software to perform general-purpose or specialized tasks.

Input → Processing → Output → Storage

Characteristics of Computers

Speed

Computers perform millions or billions of operations per second, making repetitive computation practical at large scale.

Accuracy

When software and input are correct, deterministic operations can be repeated precisely. Incorrect requirements still produce incorrect results.

Diligence

A computer does not become tired from repetition; it can execute the same programmed task consistently.

Storage

Digital systems can retain large amounts of data in RAM and persistent storage, subject to capacity and reliability constraints.

Versatility

The same general-purpose machine can run browsers, databases, development tools, games, security tools and many other workloads.

Automation

Scripts, schedulers and software can perform tasks automatically, enabling scalable administration and security operations.

Client vs Server

Client and serverA client requests a service or resource. A server listens for requests and provides a service or resource. The same physical machine can act as a client in one interaction and a server in another.

Host generally means a network-addressable computer/device that can run services or applications. A node is any device or endpoint participating in a network or distributed system. Every host can be considered a node, but a node is not necessarily called a host in every context; terminology depends on the architecture.

Data vs Information

Data is raw, unprocessed facts. Information is data processed and interpreted so it has meaning. For example, 172, 168, 190 could be raw measurements; “average score = 176.7” is meaningful information derived from them.

Drivers and middlewareA driver translates OS requests into operations understood by a specific hardware device. Middleware sits between lower-level system services and applications, providing reusable services such as web, database, messaging or application integration functionality.

ASCII and Unicode

ASCII is a character encoding based on 7 bits and defines 128 characters, including control characters, letters, digits and punctuation. Common values include 'A' = 65, 'a' = 97, and '0' = 48.

Unicode provides a universal character set/encoding ecosystem for writing text across languages and scripts. UTF-8 is a variable-length encoding that uses 1–4 bytes for a Unicode code point and preserves ASCII byte compatibility for the ASCII range.

Security note — Homoglyph / IDN homograph attacksUnicode permits visually similar characters from different scripts. An attacker may register or display a domain or identifier containing lookalike characters so it resembles a trusted name. This can support phishing and impersonation. Defenses include careful URL inspection, domain controls, browser protections, normalization-aware validation and user awareness.

1.3 Computer Architecture

Computer architecture describes the programmer-visible design and behavior of a computing system, such as its instruction set and memory model. Computer organization describes how that architecture is implemented using hardware components, buses, pipelines, caches and control circuitry.

Von Neumann Architecture

Definition — Von Neumann architectureThe stored-program concept places both instructions and data in a shared main memory, with the CPU fetching instructions and data through the system's memory and I/O mechanisms. This shared path is powerful but can create a throughput bottleneck between CPU and memory.

Core CPU Components

ALU

The Arithmetic Logic Unit performs arithmetic operations such as addition and comparisons, plus logical operations such as AND, OR and NOT.

Control Unit

Coordinates instruction execution by fetching/decoding instructions and directing data movement and control signals.

Registers

Tiny, very fast storage locations inside the CPU used for operands, addresses, instructions and execution state.

Interrupts and DMA

An interrupt is a signal/event that causes the CPU to pause or redirect normal execution to handle an urgent condition. A keyboard input can trigger an interrupt so the OS can process the new input. DMA (Direct Memory Access) lets a capable device/controller transfer data directly between a device and memory with much less CPU involvement, freeing CPU cycles for other work.

1.5 Memory

RAMRandom Access Memory is volatile working memory used to hold active programs and data. Its contents are normally lost when power is removed.
TypeCharacteristicsTypical role
ROMNon-volatile memory intended to retain firmware or other persistent data.Firmware storage; modern systems commonly use flash/EEPROM-like technology.
SRAMFast, expensive and does not require refresh like DRAM.CPU cache.
DRAMDenser and cheaper; requires periodic refresh.Main system RAM.
DDRDouble Data Rate SDRAM generations such as DDR3, DDR4 and DDR5 improve speed/efficiency.Modern system memory; generations are physically/electrically incompatible.

Memory Hierarchy

Virtual Memory, Paging and Page Tables

Virtual memory gives processes an address space managed by the OS and memory-management hardware. It can use storage as backing space when RAM is under pressure. Paging divides virtual memory into fixed-size pages, commonly 4 KiB although other sizes exist. Page tables map virtual pages to physical frames and record protection/status information.

A page fault occurs when a process references a page that is not currently mapped as resident in RAM or when an access violates the page's permitted state. For a valid non-resident page, the OS may load it from backing storage and resume execution. Swap space is storage reserved for memory backing; Windows commonly uses a pagefile such as pagefile.sys, while Linux can use a swap partition or swap file.

ThrashingThrashing occurs when a system spends excessive time moving pages between RAM and storage instead of executing useful work. It can cause severe performance degradation and may indicate memory pressure, an oversized workload, or inefficient application behavior.

Process Virtual Memory Layout

Memory Allocation, Buffers and Leaks

Memory allocation reserves memory for data structures or objects. Stack allocation is often automatic; heap allocation is typically dynamic. A memory leak occurs when a program loses the ability to reclaim allocated memory, causing memory usage to grow over time. A buffer is a reserved memory region used to hold data temporarily.

Security note — Buffer OverflowA buffer overflow occurs when software writes beyond the boundary of an allocated buffer. In classic stack-based cases, an overflow can overwrite nearby control data such as a return address and potentially influence execution. Modern mitigations include stack canaries, ASLR, DEP/NX, control-flow protections and memory-safe languages, but secure input validation and safe memory handling remain essential.

1.6 Storage

HDD

Hard Disk Drives use spinning magnetic platters and moving read/write heads. They are comparatively inexpensive per terabyte and can provide large capacities, but mechanical movement increases latency and makes them more sensitive to physical shock.

SSD

Solid State Drives use flash memory with no moving mechanical parts. They provide much lower latency and higher I/O performance than HDDs and are generally more resistant to drops, although flash has finite write endurance and SSD recovery behavior differs from HDDs.

Partitions, Volumes and Formatting

A partition is a logically separated region of a physical drive. MBR is an older partitioning scheme with limitations such as roughly 2 TiB disks under common 512-byte-sector assumptions and four primary partition entries. GPT is the modern partitioning scheme used with UEFI systems and supports much larger disks and more partition entries.

A volume is a storage unit presented to an OS and normally formatted with a filesystem. Formatting creates the filesystem structures needed to store files. A quick format primarily creates/initializes filesystem metadata, while a full format can perform additional checks depending on the OS/version.

Forensics noteDeleting a file often removes or marks its filesystem references rather than instantly erasing every underlying byte. On HDDs, unallocated data can sometimes be recovered until overwritten. SSD TRIM and flash garbage collection can make recovery more difficult because blocks may be proactively reorganized or discarded.

1.7 File Systems

Definition — File SystemA file system is the data structure and set of rules an operating system uses to organize, name, store, retrieve and protect data on storage media. It is similar to a library catalog: it records where objects are and how they are organized and accessed.

Files, Directories and Paths

A file stores data; a directory organizes references to files and other directories. An absolute path starts from a filesystem root or drive root, such as C:\Users\Alice\report.txt on Windows or /home/alice/report.txt on Linux. A relative path is interpreted from the current location, such as ../logs/app.log.

A file extension is a suffix commonly used to indicate a file type, such as .txt, .exe, .py or .pdf. Extensions are conventions and should not be trusted alone to determine a file's actual content.

1.8 I/O & Hardware Interfaces

Input vs OutputAn input device sends data into a computer, while an output device receives data from it. Some devices are both: a touchscreen accepts touch input and displays output; a network interface card (NIC) both transmits and receives network traffic.
Security note — Input devices are attack surfacesPhysical input interfaces can be abused. Keyloggers can capture keystrokes, and malicious USB devices can impersonate keyboards or other peripherals and inject input. Security controls include device restrictions, endpoint monitoring, physical security and user awareness.

1.9 Boot Process

Boot Stages

Power OnThe power supply and motherboard initialize electrical power. The CPU begins execution from a defined reset/start location according to the platform architecture.
POST — Power-On Self-TestFirmware performs basic hardware initialization and diagnostics. Hardware failures may produce error messages, status codes or beep patterns depending on platform.
BIOS vs UEFIBIOS is the older firmware model, historically associated with 16-bit real-mode execution, MBR booting and practical 2 TiB disk limitations under common configurations. UEFI is the modern firmware interface, commonly operating in a 64-bit environment, using GPT-capable boot mechanisms and supporting Secure Boot.
BootloaderA small program that locates and starts the OS kernel. Windows uses Windows Boot Manager; Linux systems commonly use GRUB. A bootloader can present multiple operating systems in a dual-boot setup.
Kernel LoadingThe bootloader loads the operating-system kernel into memory and transfers execution to it. Windows commonly uses ntoskrnl.exe; Linux distributions commonly load a compressed kernel image often named vmlinuz.
Drivers & ServicesThe kernel and early userspace initialize hardware drivers and system components. Linux systems commonly use systemd to start services; Windows uses the Service Control Manager and related mechanisms.
Login ScreenThe OS presents an authentication interface or service so a user can establish an authenticated session and receive the permissions associated with that identity.
Security info — Secure BootSecure Boot is a UEFI feature that verifies trusted digital signatures in the boot chain. It helps prevent unauthorized bootloaders and some bootkits—malware designed to load before or alongside the OS so it can evade ordinary OS-level security controls.

1.10 Virtualization

Definition — VirtualizationVirtualization creates software-defined representations of computing resources such as CPUs, memory, disks and network interfaces. A virtual machine (VM) behaves like an independent computer while its resources are ultimately provided by a physical host.

  • Virtual RAM: guest-visible memory backed by physical memory.
  • Virtual disk: virtual storage represented by files/images such as VDI, VMDK or VHD.
  • Virtual NIC: virtual network adapter connected through a virtual switch/network mode.

Snapshots and Cloning

A snapshot records a VM's storage/state at a point in time so it can be reverted after testing. Snapshots are not substitutes for independent backups. Full cloning creates an independent VM copy; linked cloning shares a base image and stores differences, saving space but creating a dependency on the base.
